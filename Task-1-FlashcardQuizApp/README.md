# Task 1: Flashcard Quiz App

An interactive and dynamic web-based Flashcard Quiz Application developed for the CodeAlpha App Development Internship program.

---

## 🌟 Key Features

* **Interactive Flashcards:** Smooth flip animations to reveal answers instantly.
* **SRS / Leitner Revision System:** Smart algorithm that repeats cards based on performance for better memory retention.
* **Multiple Modes:** Supports Practice, MCQ, and Exam modes.
* **Audio & Visual Feedback:** Custom sound effects and theme adjustments for an engaging experience.
* **Progress & Analytics:** Real-time tracking of test performance and progress stats.
* **Certificate Generator:** Generates a downloadable PDF completion certificate after finishing tests.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling:** Custom CSS animations, Responsive UI Design
