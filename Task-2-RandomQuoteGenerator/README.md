# Task 2: Random Quote Generator

An interactive, clean, and responsive web application built for the **CodeAlpha App Development Internship** program. This app fetches dynamic inspirational quotes, features direct social media sharing, and includes copy-to-clipboard functionality with customizable background visual themes.

---

## 🚀 Key Features

* **🎲 Dynamic Quote Fetching:** Generates fresh motivational and inspirational quotes at the click of a button.
* **🏷️ Author & Category Tags:** Clearly attributes authors and context tags for every retrieved quote.
* **📲 Social Sharing Integration:** One-click functionality to instantly post quotes directly to Twitter/X.
* **📋 Copy to Clipboard:** Built-in dynamic feedback toast to quickly copy quote text and author details.
* **🎨 Visual Theme Customization:** Dynamic gradient backgrounds and modern UI transitions that adjust automatically on user action.
* **📱 Fully Responsive Layout:** Clean, mobile-friendly design built with flexible CSS layout systems.

---
