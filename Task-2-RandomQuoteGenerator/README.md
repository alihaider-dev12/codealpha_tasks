# Task 2: Random Quote Generator

An interactive web application built for the CodeAlpha Internship program that fetches and displays inspirational quotes with dynamic social sharing features.

---

## 🌟 Features

* **Dynamic Quote Generation:** Displays fresh quotes at the click of a button.
* **Category/Author Display:** Clean layout showing quote text along with author details.
* **Social Sharing:** One-click sharing options (Twitter/X or copying quote to clipboard).
* **Responsive UI:** Clean and modern design that works seamlessly across mobile and desktop browsers.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling:** Custom CSS Flexbox/Grid animations

---

## 🚀 How to Run

1. Clone or download the repository.
2. Open `index.html` in any web browser.
