# CodeAlpha App Development Internship Tasks

This repository contains all the app development tasks completed during the CodeAlpha Internship program.

---

## 📁 Projects Overview

### 1. Task 1: Flashcard Quiz App
* **Directory:** `Task-1-FlashcardQuizApp/`
* **Description:** An interactive web-based study tool featuring Leitner SRS revision, practice/exam modes, and certificate generation.
* **Tech Stack:** HTML5, CSS3, JavaScript (ES6+), LocalStorage

### 2. Task 2: Random Quote Generator
* **Directory:** `Task-2-RandomQuoteGenerator/`
* **Description:** An interactive application that generates random inspirational quotes with social sharing options.
* **Tech Stack:** HTML5, CSS3, JavaScript (ES6+)
