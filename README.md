# CodeAlpha Frontend Development Internship Tasks

This repository contains all the frontend development tasks completed during the CodeAlpha Internship program.

---

## 📁 Projects Overview

### 1. Task 2: Random Quote Generator
* **Directory:** `Task-2-RandomQuoteGenerator/`
* **Description:** An interactive application that generates random inspirational quotes with social sharing options.
* **Tech Stack:** HTML5, CSS3, JavaScript (ES6+)

### 2. Task 3: Flashcard Quiz App
* **Directory:** `Task-3-FlashcardQuizApp/`
* **Description:** A web-based study tool featuring Leitner SRS revision, practice/exam modes, and certificate generation.
* **Tech Stack:** HTML5, CSS3, JavaScript (ES6+), LocalStorage
