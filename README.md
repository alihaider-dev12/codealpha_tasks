# CodeAlpha App Development Internship Tasks

This repository contains all the app development tasks completed during the **CodeAlpha Internship** program. The projects demonstrate interactive web applications, spaced repetition study platforms, state management, local storage mechanics, and dynamic UI/UX design.

---

## 📁 Repository Overview

| Task | Project Name | Description | Tech Stack | Status |
| :--- | :--- | :--- | :--- | :---: |
| **Task 1** | [Flashcard Quiz App](./Task-1-FlashcardQuizApp) | Interactive study platform with Leitner SRS system, practice/exam modes & certificate export. | HTML5, CSS3, JS (ES6+), LocalStorage | ✅ Completed |
| **Task 2** | [Random Quote Generator](./Task-2-RandomQuoteGenerator) | Dynamic inspirational quote generator with category tags, social media sharing & clipboard features. | HTML5, CSS3, JS (ES6+), Fetch API | ✅ Completed |

---

## 🚀 Projects Detail

### 1. 🃏 Task 1: Flashcard Quiz App
* **Directory:** [`Task-1-FlashcardQuizApp/`](./Task-1-FlashcardQuizApp)
* **Key Features:**
  * Active recall & **Leitner Spaced Repetition System (SRS)** logic.
  * Practice, MCQ, and Timed Exam testing modes.
  * Real-time progress analytics and downloadable PDF certificate generator.
  * Full offline storage persistence via `LocalStorage`.

---

### 2. 🎲 Task 2: Random Quote Generator
* **Directory:** [`Task-2-RandomQuoteGenerator/`](./Task-2-RandomQuoteGenerator)
* **Key Features:**
  * Instant random quote generation with author and context tags.
  * Direct one-click sharing integration for Twitter/X and copy-to-clipboard toast feedback.
  * Dynamic visual themes with smooth modern CSS transitions and layouts.
